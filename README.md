# Shivam Sanadhya – Portfolio

Static site (HTML, CSS, JavaScript). No build step.

- `index.html` – all content
- `css/style.css` – theme (navy #14243A, cyan #22C7D9, white, light grey)
- `js/main.js` – footer year
- `assets/Shivam_Sanadhya_Resume.pdf` – file behind the Download Resume button (replace with a newer PDF using the same name)

## Preview locally
Open `index.html` in a browser.

## Deploy free
- **Netlify Drop:** go to app.netlify.com/drop and drag this folder in. You get a public URL immediately.
- **GitHub Pages:** create a repo, upload these files, then Settings > Pages > Deploy from branch `main` / root. URL: `https://<username>.github.io/<repo>/`
- **Vercel:** import the GitHub repo at vercel.com/new, framework "Other", no build command.
- **Cloudflare Pages:** connect the repo, leave build command empty, output directory `/`.
